## Project Overview

The purpose of my project is create a cozy low-stress game contolling the actions of a cat.

## Features

- List the key features of the project, including:
    - **Animations**:  FromTo, To GSAP animations: used scale, power1.out, y- axis
    - **Sound Effects**: On specific events, triggered by users, they can hear sound effects. For example, the light switch it will show a visible cue and a sound effect.
    - **User-triggered Events**: click, mouseover, mouseout 
    - **Responsive Design**: The design is really responsive because of the max width and max height is set to 100 vh/vw. I addition, my text is made by rem. This means the elements are scaling to the container.

## Technologies Used

- List the technologies and tools used in the project:
    - **Languages**: HTML, CSS, JavaScript
    - **Libraries**: GSAP for animiations
    - **Other**: GitHub Pages for hosting, Pinterest for inspiration and photos, Youtube for tutorials, and procreate for design
